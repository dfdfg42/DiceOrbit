## 몬스터 의도 설명 (2026-10-05)

몬스터가 다음에 무엇을 하는지는 마우스를 올리지 않아도 읽혀야 한다. 말풍선(아이콘) 오른쪽에 **설명 칩**을 늘 띄운다.

- **글은 기술 설명 그대로다**: `SkillData.description` (몬스터 프리셋의 각 기술, 인스펙터에서 편집). 설명 자체를 간결하게 쓴다 — 한두 줄,
  첫 줄 = 무슨 일이 일어나나("{피해} 피해 · 대상 좌우 2칸", "점액 1칸 설치"), 둘째 줄 = 조건·부연("피해 10 이상 주면 취소", "대상을 따라 움직임").
  요약을 따로 두지 않는다 (처음엔 긴 설명 + 짧은 요약 두 벌이었는데, 사용자 결정으로 설명 하나로 합쳤다 — 두 글이 어긋날 일이 없다).
- **`{피해}`만 계산한다**: `MonsterIntentText.PreviewDamage` — 파이프라인 시뮬레이션(취약·쇠약·방어도 반영). 0.3초마다 다시 계산한다.
- **보여 주는 곳은 전부 `MonsterIntentText`를 거친다** — 어디서나 같은 글, 같은 숫자:
  ① 말풍선 옆 칩(`MonsterUI` — `MonsterCanvas/IntentSummary`, PlainPanel 배경 + 글, 둘째 줄은 작고 흐리게, 이름표는 칩 위로 비켜 선다)
  ② 몬스터 턴의 행동 말풍선(`MonsterActionLabel` — "박치기 — 15 피해 · 대상 좌우 2칸", 첫 줄만)
  ③ 정보 패널의 다음 행동·말풍선 호버 툴팁(`UnitInfoBuilder`). 예전의 "예상 피해: N" 줄은 없앴다 — 숫자가 설명 안에 들어 있다.
- 설명을 코드에서 만드는 기술(`FactionDebuffSkill`처럼 `Description`을 재정의)도 같은 형식으로 낸다.
- 설명이 비어 있는 기술은 칩을 띄우지 않고 에러를 한 번 남긴다 (기술 이름 같은 다른 글로 대체하지 않는다).
- **새 몬스터 기술을 넣을 때**: 설명을 위 형식으로 쓴다. 메뉴 **DiceOrbit → Run Monster Intent Self-Tests**가 모든 프리셋을 훑어
  빈 설명, 3줄 이상, 한 줄 20자 초과, `{피해}`를 쓰는데 예상 피해가 0인 기술, 피해를 주는데 `{피해}`가 없는 기술을 잡는다.
- 예전의 "공격/특수" 한 단어 라벨(`showIntentText`)은 껐다 — 설명 칩이 대신한다.

## 레이어 규칙

- 인디케이터는 **조회/의도 표시 중에만** 존재 — 상시 표시는 HP바·상태 아이콘뿐
- 타게팅 시작 시 조회성 인디케이터(패시브 구역 테두리 등) 자동 숨김 (조준 화면을 어지럽히지 않기)
- 전체화면 UI 진입 시 `BattleInfoPanelUI.SetVisible(false)`가 월드 인디케이터도 일괄 정리

## 기각/철거된 형태 (재도입 금지 사유 포함)

- **코밋 트레일(빙글빙글 도는 선)** — 스킬/패시브/목적지 세 의미에 겹쳐 쓰여 혼란 → 전면 철거
- **타일 틴트 글로우(패시브 범위)** — 몬스터 공격 오버레이와 색 면이 겹침 → 브래킷으로 대체 (그 브래킷도 아래 항목으로 철거)
- **타일 모서리 ㄱ자 브래킷(패시브 범위)** — 패시브가 전부 구역 단위가 됐는데 타일마다 4개씩 그려 구역 하나에 20개, 마력 회로는 60개. 구역 플레이트와 따로 놀아 "이 구역"으로 읽히지 않음 → 구역 테두리로 대체 (2026-10-04)
- **구역 위 월드 꼬리표(패시브 지금 효과)** — 구역 안쪽은 몬스터 이름·HP 바, 바깥쪽은 캐릭터 머리 위 UI와 겹친다 → 정보 패널 패시브 제목 옆으로 (2026-10-04)
- **구역 브래킷(중앙 V자 + 모서리 ㄱ자 LineRenderer)** — 낙서처럼 읽히고 구역 범위가 안 보임 → 잉크 플레이트로 대체 (2026-09-25). 플레이트 정렬은 방 배경 스프라이트(order −100)보다 앞, 발밑 마커(−1)보다 뒤 = −50
