# 캐릭터 시트 동기화 A — 캐릭터 수치·상태이상 지속 (설계)

> 상태: 확정 (2026-10-09, 토론 결과) · 출처: `Dice Orbit-게임 컨텐츠 마스터 리스트_261003.xlsx`(이하 "시트")의 「캐릭터」「버프·디버프」 시트
> 전체 작업은 A(캐릭터 수치) → B(공용 모디파이어 17종 + 충전) → C(직업 고유 16종) 세 단계로 나눈다. 이 문서는 **A만** 다룬다.
> 대상: 현존 캐릭터 4종(전사·도적·마법사·연금술사). 시트의 나머지 9직업은 반영하지 않는다.

## 1. 목표

현존 캐릭터 4종의 스탯·패시브·3단계 콤보·관련 상태이상 수치를 시트와 일치시키고, 감전·고양·약화의 지속 방식을 시트의 "이번 턴 동안"으로 바꾼다.

## 2. 확정된 결정

| # | 결정 | 근거 |
|---|---|---|
| D1 | 감전·고양·약화는 **부여된 라운드가 끝날 때까지 모든 해당 공격에 적용**되고 소모되지 않는다 | 시트 "이번 턴 동안". 시트 공통 규칙이 "이전 턴 = 이전 플레이어 턴 시작 ~ 몬스터 턴 종료"로 정의하고, 보급만 "이번 플레이어 턴이 끝날 때까지"로 따로 구분 → 시트의 "턴" = 라운드(플레이어 턴 + 몬스터 턴) |
| D2 | 라운드형 상태는 **몬스터 턴 종료 시점(타일 지속시간 감소 직후)에 일괄 제거**하고, **전투 시작 시에도** 제거한다 | 종료 시점이 코드 한 곳에 보인다. 캐릭터는 전투 사이에 살아남으므로 고양이 다음 전투로 새는 것을 막는다. 기존 Duration 카운터는 "주인의 턴 시작"에 감소해 몬스터의 약화가 공격 전에 사라지므로 쓰지 않는다 |
| D3 | 촉매는 1회성(`OneShotActionStatus`) 그대로 둔다 | 시트도 "다음 공격" |
| D4 | 중독 타이밍은 현재 방식(대상의 턴 시작) 유지 | 사용자 결정 — 시트(플레이어 턴 종료)와 다름을 알고 유지 |
| D5 | 도적 3단계 이름은 "죽음의 촉매", 연금술사 콤보 이름은 "연성 콤보" 유지 | 시트의 "[대지 가르기]"(도적), "마력 콤보"(연금술사)는 복사 실수로 판단 — 사용자 결정 |
| D6 | 라운드형 상태도 비중첩: 이미 있으면 합산하지 않고 **두 값 중 큰 쪽**을 유지한다 | 시트 "중첩되지 않습니다". 재부여 시 수치가 다를 때의 처리는 시트가 미기재 → 집중 주사위(고양 15%) 뒤에 연금술사 고양(25%)을 받으면 25%가 되도록 큰 값을 택한다 |

## 3. 변경 내용

### 3.1 상태이상 구조

- 새 추상 클래스 `RoundStatus : StatusEffect` (`Combat/Effects/ActionStatuses.cs`에 함께 둔다)
  - `AppliesTo(AttackContext)` / `Modify(AttackContext)`를 자식이 정의 (기존 `OneShotActionStatus`와 같은 모양)
  - `OnAttack`: `OnCalculateOutput`에서 해당하면 `Modify`만 한다. 소모·제거하지 않는다. 직접 체력 손실(`IsDirectHpLoss`)엔 개입하지 않는다
  - Duration = -1 (제거는 D2의 라운드 종료 처리가 담당)
- `ShockStatus`, `InspireStatus`, `WeakenStatus`의 부모를 `OneShotActionStatus` → `RoundStatus`로 바꾼다. 클래스 이름·`EffectType` 값은 그대로 (enum 정수 직렬화 보호)
- `StatusEffectManager`에 `RemoveRoundStatuses()` 추가: 보유한 `RoundStatus`를 전부 제거
- `CombatManager`
  - `EndMonsterTurnRoutine`에서 `TileTurnEnd()` 직후, 살아 있는 모든 캐릭터·몬스터에 `RemoveRoundStatuses()` 호출
  - `StartCombat`(콤보·행동 스코프 초기화하는 곳)에서 파티 전원에 `RemoveRoundStatuses()` 호출
- 툴팁·키워드 설명(`TooltipKeywordFormatter` 등)의 감전·고양·약화 문구를 "이번 턴 동안 …"으로 갱신

### 3.2 스탯·패시브

| 캐릭터 | 공격력 | 패시브 |
|---|---|---|
| 전사 | 6 → **5** | 방진 10% (변경 없음) |
| 도적 | 4 → **5** | 협공 30% → **20%** |
| 마법사 | 5 (변경 없음) | 마력 회로 (변경 없음) |
| 연금술사 | 4 → **5** | 시약 준비 3개 / 촉매 25% (변경 없음) |

### 3.3 3단계 콤보

| 캐릭터 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 전사 | **대검 베기** 120%, 현재 구역 | **균열 베기** 120%, 현재+양옆 | 대지 가르기 **150%**, 전체 + 모든 아군 방어도 **5** |
| 도적 | 쌍비수 **60%** × 2 | 맹독비수 **75%** × 3, 행동을 마친 뒤 대상에게 중독 **5** (기존: 타격마다 2) | 죽음의 촉매 **100% × 4**, 대상 중독 2배 |
| 마법사 | 비전 화살 **120%**, 범위 안 가장 가까운 1명 | 연쇄 번개 **120%**, 가장 가까운 2명 + 감전 25% | 궤도 붕괴 **150%**, 범위 안 전체 + **감전 25% (신규)** |
| 연금술사 | 산성 플라스크 **120%**, 현재 구역, **약화 없음** (기존: 약화 부여) | 촉매 살포 **120%**, 현재+양옆 + 약화 25% | 현자의 폭탄 **150%**, 전체 + 모든 아군 고양 **25%** |

- 도적 2단계 중독 5는 "대상마다 행동 1회당 5"로 처리한다 (타격 수와 무관)
- 연금술사 1단계 약화 제거에 맞춰 코드의 약화 부여 조건을 `stage <= 1` → `stage == 1`로 바꾼다

### 3.4 값의 위치

수치는 두 곳에 있으므로 **둘 다** 바꾼다. 에셋 값이 코드 기본값보다 우선한다.

1. 프리셋 에셋 (Git LFS): `Assets/Scripts/Data/Character Preset/{Warrior,Rogue,Mage,Alchemist}/*.asset`
   - YAML 손편집 규칙: `references.RefIds`의 `data`만 고치고 `rid`는 유지. 한글은 기존 표기(\u 이스케이프/리터럴)를 그대로 따른다
2. 코드 기본값: `WarriorGreatswordActive.cs`, `RogueAmbushActive.cs`, `MageEnergyBallActive.cs`, `AlchemistThrowActive.cs`, `RogueFlankPassive.cs`
   - 마법사 3단계 감전은 새 필드 `stage3ShockPercent`(기본 25)가 아니라 기존 `shockPercent`를 2·3단계가 함께 쓴다

설명문도 함께 갱신한다: 에셋의 `skillName`·`description`(콤보 설명의 단계 이름), 코드의 `GetStageName`·`GetStageDescription`, 패시브 `description`.

### 3.5 함께 고칠 곳

- 튜토리얼 `Core/Tutorial/TutorialScenario.cs:198, 201`의 "협공 +30%" → 20%
- 특수 주사위 `DieEffect.cs`(고양 등을 부여하는 효과)의 설명·수치가 "다음 공격" 전제면 "이번 턴"으로 갱신
- 행동 예고 자가 테스트 `Editor/ActionForecastSelfTests.cs`가 1회성 소모를 전제로 한 단언이 있으면 새 규칙에 맞게 수정

## 4. 범위 밖

- 중독 타이밍(D4), 시트 "미기재" 규칙, 몬스터 수치
- 공용 모디파이어(B), 직업 고유 모디파이어·고전압/고순도 촉매 같은 상태 강화 규칙(C)
- 시트의 다른 9직업

## 5. 검증

1. 헤드리스 컴파일 (VS2022 MSBuild, Unity 6000.3.8f1 mono 4.7.1-api)
2. 에디터 자가 테스트 추가 (`Editor/CombatRedesignSelfTests.cs`)
   - 라운드형 상태가 같은 라운드의 공격 두 번에 모두 적용된다
   - `RemoveRoundStatuses()` 뒤에는 적용되지 않는다
   - 촉매는 여전히 한 번 쓰면 사라진다
3. 에셋 값 검증: 파이썬으로 YAML을 읽어 바뀐 필드만 ASCII로 출력해 표 3.2·3.3과 대조
4. 사용자 플레이 확인
   - 마법사 2단계 감전 뒤, 같은 턴 다른 캐릭터의 공격에도 +25%
   - 약화 건 몬스터의 다음 몬스터 턴 공격이 25% 감소
   - 다음 라운드엔 감전·약화·고양이 모두 사라짐
   - 툴팁·튜토리얼 문구가 새 수치
