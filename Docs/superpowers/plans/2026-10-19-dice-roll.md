# 3D Dice Roll Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Roll rounded 3D dice in the screen center, hold readable results, then deliver them to the existing bottom slots.

**Architecture:** A procedural mesh and isolated render camera provide the 3D overlay. DiceRollAnimator owns timing and cleanup; existing DiceData and slot elements remain authoritative.

**Tech Stack:** Unity 6000.3.8f1, URP, uGUI, TextMeshPro.

**Spec:** User-approved flow in this conversation: 중앙에서 굴림 → 결과 → 하단 슬롯.

## Global Constraints

- Preserve dice rules, custom faces, special die artwork, tutorial locks and selection behavior.
- Do not consume gameplay random numbers for presentation.
- Preserve the user's open, unsaved BattleScene; validate in a separate copy.
- Apply to the existing production animator component without requiring scene edits.

## Review Focus

- Zero, negative and multi-digit face values stay readable and match data.
- Repeated rerolls and cancellation leave no hidden or orphaned dice.
- Hidden panels and scene teardown release render resources.
- Layout changes and aspect ratios keep the final overlay aligned with slots.
- Special dice retain their face artwork and number colors.
